# kptracer

`kp_phs_all.py`: six reconstructions, random trees and their cPHS, parsimony and likelihood. `save_kp_trees.py`: the tree deposit. `check_trees.py`: compares deposited trees with the scored ones. `nni_analysis_v2.py`: NNI perturbation (Appendix P). `count_states.py`: number of mutated states per site.
