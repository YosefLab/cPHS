# trees

For each of the 63 analyzed tumors: the MaxCut, SMJ, Spectral and Spectral Greedy reconstructions and the five random trees scored in the paper, as Newick with branch lengths (`save_kp_trees.py`). `parsimony.csv` in each folder gives each tree's parsimony, the MaxCut seed, and cPHS where recomputed. `unmatched.csv` lists every tree whose parsimony differs from the scored tree, with both cPHS values and whether the accept/reject decision changes.
