# trees

For each of the 63 analyzed tumors, the trees scored in the paper, as Newick: the Cassiopeia (`cassiopeia.nwk`) and Neighbor Joining (`nj.nwk`) trees published by Yang et al. (2022), Zenodo DOI 10.5281/zenodo.5847462 (NJ with internal node labels removed, as scored); the MaxCut, SMJ, Spectral and Spectral Greedy reconstructions (with branch lengths, `save_kp_trees.py`); and the five random trees (`random_0.nwk` to `random_4.nwk`). `parsimony.csv` in each folder records each reconstruction's parsimony and solver seed.
